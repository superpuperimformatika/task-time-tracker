
# Система учёта времени выполнения задач

## Описание проекта

Проект разработан в рамках практического задания к лекции №5
«Этапы разработки программного продукта» по дисциплине
«Проектирование и разработка бизнес-ориентированного
программного обеспечения».

Программа представляет собой модуль учёта времени,
интегрированный с системой управления задачами.

Приложение позволяет создавать задачи, запускать и
останавливать таймер, учитывать общее затраченное время
и формировать отчёты.

## Цель работы

Разработать программный модуль учёта времени для системы
управления задачами с использованием языка Python.

## Основные возможности

- Создание задач с названием и описанием.
- Просмотр списка созданных задач.
- Изменение статуса задачи.
- Запуск и остановка таймера.
- Суммирование времени нескольких рабочих сессий.
- Отображение времени в формате ЧЧ:ММ:СС.
- Формирование отчётов по задачам.
- Сохранение отчётов в текстовый файл.
- Автоматическое тестирование программных компонентов.

## Используемые технологии

- Python 3.12 — язык программирования.
- GitHub — хранение исходного кода.
- GitHub Actions — автоматическое тестирование.
- unittest — проверка корректности работы программы.
- unittest.mock — имитация временных значений.
- time — измерение продолжительности работы.
- datetime — работа с датой и временем.
- pathlib — сохранение отчётов.

Дополнительные сторонние библиотеки не требуются.

## Описание программных модулей

### timer.py

Реализует класс Timer для запуска и остановки
таймера, подсчёта общего затраченного времени
и преобразования секунд в часы, минуты и секунды.

### task_manager.py

Содержит класс TaskManager, обеспечивающий создание
задач, получение информации о них, изменение статусов
и взаимодействие с таймером.

### reports.py

Содержит класс ReportGenerator, предназначенный
для формирования текстовых отчётов по задачам
и сохранения результатов в TXT-файл.

### main.py

Главный модуль программы с консольным меню
для взаимодействия с пользователем.

## Инструкция по запуску

Для запуска программы необходимо установить Python 3.12
или совместимую версию Python 3.

1. Скачать репозиторий на компьютер.
2. Распаковать архив проекта.
3. Открыть терминал в папке проекта.
4. Выполнить команду:

```bash
python main.py
```

После запуска появится консольное меню.

## Работа с программой

Пользователь может выбрать следующие действия:

1. Создать задачу.
2. Просмотреть задачи.
3. Запустить таймер.
4. Остановить таймер.
5. Посмотреть затраченное время.
6. Изменить статус задачи.
7. Завершить задачу.
8. Сформировать отчёт.
9. Сохранить отчёт в файл.
0. Выйти из программы.

## Автоматическое тестирование

Для проверки корректности работы программы
используется стандартная библиотека unittest.

Подготовлено 16 автоматических тестов,
проверяющих основные функции приложения.

Для локального запуска тестов используется команда:

```bash
python -m unittest discover -s . -p "test_*.py" -v
```

Автоматический запуск тестов настроен с помощью
GitHub Actions.

Тестирование выполняется при отправке изменений
в репозиторий и при создании pull request.
Также предусмотрен ручной запуск.

## Ограничения текущей версии

- Задачи хранятся в оперативной памяти и не
  сохраняются после закрытия программы.
- Интеграция реализована с собственным менеджером задач.
- Подключение к внешним системам управления задачами
  не предусмотрено.

## Заключение

В результате выполнения практического задания
разработан программный модуль учёта времени,
обеспечивающий управление задачами, запуск
и остановку таймера, накопление затраченного
времени и формирование отчётов.

Для проверки программных компонентов
подготовлены автоматические тесты и настроен
их запуск с помощью GitHub Actions.
